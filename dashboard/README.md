# Kreo Dashboard

This folder contains the Next.js dashboard for the Kreo Discord music bot.

For full installation, environment configuration, Discord OAuth setup, bot bridge setup, and production deployment steps, read the root project guide:

- `../README.md`
- `../SETUP_GUIDE.md`

Common dashboard commands:

```bash
npm install --prefix dashboard
npm run dev --prefix dashboard
npm run build --prefix dashboard
npm run start --prefix dashboard
```

The dashboard requires `dashboard/.env.local` in development or equivalent environment variables in production.
