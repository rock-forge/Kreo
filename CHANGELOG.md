# Changelog

## 1.0.0

Initial public source release of the Kreo bot and dashboard.

- Discord music playback with Lavalink, queue controls, filters, saved songs,
  playlists, and owner tools.
- Purple Next.js dashboard with Discord login, server selection, search,
  playback controls, queue management, playlists, and server settings.
- Responsive navigation, desktop artwork, pinned servers, recent rooms, and
  keyboard page search.
- Dashboard playback resolution and idle voice refresh improvements.
- Guild-scoped bridge authorization and short-lived Socket.IO tickets.
- Owner-aware help menus, application emoji support, and welcome-link validation.
- Configuration examples, local and production setup instructions, third-party
  notices, and automated validation.

The project licence governs use and redistribution. This release does not bundle
installed dependencies or production credentials.
